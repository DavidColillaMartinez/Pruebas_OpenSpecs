## ADDED Requirements

### Requirement: Responsive landing page shell
The system SHALL provide a responsive single-page landing layout for a bathroom products store using React, Vite, and Tailwind.

#### Scenario: Desktop landing loads
- **WHEN** a visitor opens the landing page on a desktop viewport
- **THEN** the system displays a complete landing page with navigation, hero content, product-focused sections, and a contact or consultation call to action

#### Scenario: Mobile landing loads
- **WHEN** a visitor opens the landing page on a mobile viewport
- **THEN** the system displays the same core content in a readable single-column layout without horizontal scrolling

### Requirement: Powerful visual header
The system SHALL include a visually prominent header and hero section with layered composition, store messaging, product imagery, and primary calls to action.

#### Scenario: Hero communicates offer
- **WHEN** a visitor views the first screen of the landing page
- **THEN** the system shows the store category, a concise value proposition, at least one primary call to action, and visual references to bathroom products

#### Scenario: Header supports navigation
- **WHEN** a visitor uses the header navigation
- **THEN** the system provides clear links or controls to reach the main landing sections

### Requirement: Product category presentation
The system SHALL present the main product categories sold by the store, including shower screens, shower trays, taps, and bathroom-related accessories.

#### Scenario: Visitor reviews categories
- **WHEN** a visitor reaches the category section
- **THEN** the system displays each core product category with a title, short commercial description, and visual treatment

### Requirement: Minimal premium visual style
The system SHALL use a minimal, modern visual style with restrained color, layered surfaces, shadows, spacing, and typography to create a premium bathroom retail impression.

#### Scenario: Landing uses layered design
- **WHEN** a visitor scrolls through the landing page
- **THEN** the system presents sections with intentional depth using cards, shadows, contrast, and layered backgrounds without visually overwhelming the content

### Requirement: Conversion-focused content
The system SHALL include conversion-oriented content that guides visitors toward requesting advice, exploring products, or contacting the store.

#### Scenario: Visitor reaches conversion section
- **WHEN** a visitor reaches the final commercial section
- **THEN** the system shows a clear call to action for consultation, contact, or product exploration
