# Inventario de recursos conservados

assets/Boceto/Imagen_Original.png es material original del propietario. Esta limpieza no altera originales, medios ni recursos de la web.

public contiene los recursos públicos del proyecto. Las referencias a medios servidos externamente se mantienen en el código y deben verificarse contra su contenido antes de cambiarlas. Un URL público de imagen no es una credencial.

El catálogo local de trabajo queda excluido por .gitignore. No subir paquetes completos, exportaciones privadas, datos de terceros ni configuración administrativa para documentar recursos. Conservar únicamente las referencias públicas y evidencias resumidas necesarias para el proyecto.
