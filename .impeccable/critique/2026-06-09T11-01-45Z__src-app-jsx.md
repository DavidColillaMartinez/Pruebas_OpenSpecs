# UX Design Review: Bath Studio Landing Page

**Target**: src/App.jsx (full single-page site)
**Register**: Brand — design IS the product
**Refactor context**: Post-fix of six priority issues from previous critique (score was 18/40)

## 1. AI Slop Verdict

**Verdict**: Partial pass. The refactor killed the worst tells (hero metrics, auto-carousel, backdrop-blur sprawl, eyebrow spam), so the page no longer screams "AI made this." But a trained eye still catches the reflex in three places.

**Bans compliance:**
- Side-stripe borders: PASS
- Gradient text: PASS
- Glassmorphism as default: PASS (backdrop-blur confined to nav per rules)
- Hero-metric template: PASS (removed in refactor)
- Identical card grids: **FAIL** (4 structurally identical category cards + 3 identical process steps)
- Tiny uppercase tracked eyebrow above every section: **BORDERLINE** (removed from section headers but persists on all 4 category cards as `tracking-[0.22em]` labels)
- Numbered section markers as default scaffolding: PASS (used only for real 3-step process)
- Large rounded-corner icons above every heading: PASS
- Mono as lazy tech shorthand: PASS
- Timid palette: **BORDERLINE** (warm-near-white band is the saturated AI default, but brand commits to restraint via DESIGN.md)
- Zero imagery: PASS (5 Unsplash photos)
- Editorial-typographic lane as default: **PARTIAL** (page IS editorial-restraint, but brand explicitly invokes Aesop/Le Labo)
- **Uniform reveal reflex**: All sections share identical `[data-reveal]` opacity+translateY — the tell is "one identical entrance applied to every section"

## 3. Cognitive Load Assessment

3 of 8 items failed:
- **Single focus**: FAIL — 4 equal category cards demand parallel comparison
- **One thing at a time**: FAIL — category section presents 4 simultaneous items
- **Progressive disclosure**: FAIL — all content visible on scroll, no differentiation between featured and secondary
- Pass: Chunking, Grouping, Visual hierarchy, Minimal choices, Working memory

Moderate cognitive load. Category section is the primary overload point.

## 4. Emotional Journey (Peak-End Rule)

1. Hero (Peak #1): Strong entrance — mist blur, bold headline, ProductPanel. Intrigue + confidence.
2. Categories (Valley): Information density spike. 4 identical cards = scanning behavior, mild overwhelm.
3. Method/Process (Dip → Recovery): Dark panel creates visual break. Functional but not emotional.
4. Editorial Spread (Peak #2): Strongest post-hero moment. Poetic headline, large photo, material tags.
5. Contact + Footer (End): Solid dark closure. Clay CTA is correctly unique. But mailto: only is a cold end.

Arc: high → flat → dip → high → medium. Acceptable; process section needs energy; contact could end stronger.

## 5. Strengths

1. **Copy is genuinely premium.** Spanish-language copy avoids every cliché. Concrete, specific, no buzzwords. "Banos limpios, precisos y con presencia" is strong. Each category has real value propositions.
2. **Shadow taxonomy is working.** Soft→lift→glass progression creates depth without glassmorphism. The Float Rule is correctly and consistently applied.
3. **Image fallbacks and reduced-motion support are properly implemented.** Gradient backgrounds on img elements, prefers-reduced-motion media query correctly overrides all animations and reveals.

## 6. Priority Issues

### [P1] Identical category card grid violates "identical card grids" ban
**Fix**: Break the grid. Use one featured/full-width card + three smaller, or staggered masonry layout. The editorial spread proves asymmetric layout skill.

### [P1] Uniform reveal animation reflex
**Fix**: Differentiate reveal per section. Hero: clip-path/blur reveal. Categories: staggered card reveals. Editorial: scale+blur. Process: sequential. Add section-specific modifier classes.

### [P2] Tiny uppercase tracked labels on all 4 category cards
**Fix**: Labels should differentiate, not decorate. Keep only on 1-2 most distinctive products. Replace others with different visual treatment or remove.

### [P2] Contact section ends with email only — no phone, form, or calendar
**Fix**: Add tel: link at minimum. Better: lightweight inline form that captures momentum without page navigation.

### [P3] No OG image — social shares are invisible
**Fix**: Add og:image and twitter:image meta tags. Use the editorial spread image as the strongest visual asset.

## 7. Persona Red Flags

**Jordan (First-Timer)**: 4 equal cards with no browsing guidance. ProductPanel is unreadable as a bathroom product. "Envia medidas, estilo y plazo" asks for information a first-timer doesn't have. No explanation of what "asesoria" entails (cost, format, duration). Trust-building benefits buried in section 3.

**Casey (Mobile)**: "Pedir asesoria" CTA in header is unreachable by thumb. Heavy scroll distance on mobile (4 h-52 cards + h-80 editorial image). No tel: link — mailto: only. No bottom-of-screen persistent action.

**Riley (Stress Tester)**: JS failure = all sections ship invisible (opacity:0 in CSS, reveals never fire). mailto: uses .local TLD (placeholder leak). bg-white/7 may not be a valid Tailwind utility (uses arbitrary value syntax). No onerror handler on Unsplash images.

## 8. Minor Observations

- Footer mailto uses .local TLD (placeholder leak)
- No text-wrap: pretty for body copy
- ProductPanel animation loops infinitely on alternate (violates "no bounce/elastic" guidance)
- No dark mode consideration
- Editorial image wrapper shadow-glass reads as decorative rather than material
- bg-white/7 uses non-standard Tailwind opacity step
- Good: aria-label toggles between "Abrir menu" and "Cerrar menu", aria-expanded correct
